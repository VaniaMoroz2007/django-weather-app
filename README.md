# Django Weather App

Веб-додаток для пошуку погоди в будь-якому місті зі збереженням історії запитів.

## Технології
* Python, Django, SQLite
* HTML/CSS
* OpenWeatherMap API

## Запуск проекту
1. Склонуйте репозиторій.
2. Створіть віртуальне середовище та встановіть залежності: `pip install -r requirements.txt`
3. Виконайте міграції: `python manage.py migrate`
4. Запустіть сервер: `python manage.py runserver`
